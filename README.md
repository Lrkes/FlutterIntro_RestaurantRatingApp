# Restaurant Feedback Demo App

A mini full-stack demo app using **Flutter Web** + **Django REST**.  
Just starting to learn this tech stack.

This project demonstrates a simple feedback form that collects restaurant ratings and comments from a user, and sends the data from a Flutter frontend to a Django backend using HTTP.

## Features
- 🌐 Flutter Web frontend UI
- 📡 HTTP POST request to backend
- 📥 Feedback includes restaurant name, food/service/atmosphere ratings, and a comment field
- 🧪 Runs entirely locally

## Tech Stack
- Flutter (Web)
- Dart
- Django
- Python
- No database yet – just console printout of submitted data
